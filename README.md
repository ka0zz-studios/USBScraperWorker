# USBScraperWorker
This Application waits for new USB Devices and automatically copies all Contents to /Documents/ScrapedSticks/. There is a GUI version that logs everything in a Console Window and also a Worker Application that runs in the Background.

WARNING: This tool is for private use only, or on Devices you have the rights to. I am not responsible for any damage or trouble you might get in because of it. That said, have fun! :)
